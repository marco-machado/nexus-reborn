Nexus Reborn — Tripo3D Asset List

Generate each asset in the Tripo3D web app (no API), download as GLB, save to the listed path.

  • Scale: 1 unit = 1 meter, +Y up. Target size is noted per asset; rescale on import if needed.
  • Export/download GLB with PBR textures. Download immediately — Tripo download links expire.
  • Characters: verify the preview shows a complete head-to-feet T-pose body before rigging. Rig as biped, then retarget presets: idle, walk, run, shoot, hurt.
  • Props and buildings: no rigging. Prefer low face counts; these repeat many times per mission.
