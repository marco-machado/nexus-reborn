## Environment
- **Build**: `main` at `0dcb87c`, served by `npm run dev` (Vite) on port 4200
- **Platform**: Headless Chrome for Testing, 1280x720 viewport, driven by `production/qa/evidence/smoke-2026-10-19/if-010/capture.mjs`
- **Scene/Level**: World Network (`appStore.phase` = world), right after a New Operation
- **Game State**: Persistence is in write-failed state, reason `quota`. The first-visit orientation card is showing, because a New Operation resets the tutorial.

## Reproduction Steps
**Preconditions**: The IF-010 capture fixture, in which a storage write throws a quota error, so the durable erase in New Operation fails.

1. From the Menu, start New Operation. The durable erase fails.
2. World Network opens with the first-visit orientation card up (`capture.mjs:191-193`).
3. Look at the `SAVE FAILED // CAMPAIGN NOT FILED` notice and the orientation card at 1280x720.
4. Activate UNDERSTOOD (aria-label `Dismiss the orientation`). Look at the notice again.

**Expected Result**: The notice is visible and covers no other element's text. The alternative is that it is formally declared as an overlay. IF-001 AC1: "no element's bounding box intersects another's except declared overlays (Settings, Balance, pause, toasts)". The notice is not on that list.

**Actual Result**:
- At step 3 the notice box covers two pieces of orientation-card text:
  - the end of START HERE's second line ("When a sector needs hands on the ground, take its contract.")
  - the start of the STRATEGIC TIME line
- At step 4, after UNDERSTOOD, the notice persists and overlaps nothing.
- The notice text itself is not clipped.

## Technical Context
- **Likely affected files**:
  - `src/ui/ui.css:2841-2850`: `.write-fail-region` is `position: fixed; left: 50%; top: 31vh`. Its comment (2841-2846) says "31vh is the one band that covers no text on any of the four Screens at 1280x720, 1366x768 and 1920x1080, text scale 100 and 125 ... Measured by production/qa/evidence/team-qa-2026-10-15-s6/fix-verify.mjs." qa-lead R7 and IF-010 advisory 1 cite this comment as `ui.css:2705-2716`. In the current tree it sits at 2841-2850.
  - The orientation card's component was not located in this run.
- **Related systems**:
  - Persistence: the write-failure state that drives the notice.
  - The first-visit orientation and tutorial reset on New Operation.
- **Possible root cause**: the 31vh band was measured without the first-visit orientation card on screen, so the comment's no-text claim does not hold while the card is up.
- **Recommended fix direction**: route notice placement to ux-designer. Option 1: place the notice clear of the orientation card. Option 2: add the notice to IF-001 AC1's declared-overlay list. Either way, correct the `ui.css` comment (IF-010 advisory 1).

## Fix
- **Date**: 2026-10-19, on `main`. Owner ruling 2026-10-19: move the notice (not declare it an overlay).
- **Change**: `src/ui/WorldMap.tsx` `WorldOnboard` renders the failure line in the orientation card's own flow, above THE JOB (`.wm-onboard-fail`, `aria-hidden`). `src/ui/ui.css` visually hides the fixed `.write-fail-region` while `.wm-onboard-wrap` is mounted (clip, 1x1), so it stays the live region screen readers announce. After UNDERSTOOD the fixed notice shows as before.
- **Regression test**: no vitest case (no DOM test environment). The check is the browser capture below.
- **Verified**:
  - `production/qa/evidence/bug-0003-fix-2026-10-19/capture.mjs` (copy of the IF-010 smoke capture plus a BUG-0003 overlap check), `npm run dev` on port 4200, headless Chrome for Testing at 1280x720: **ALL PASS**. The visible notice sits inside the card (rect 311,120 658x29), intersects no card text (`hits: []`), and the fixed region measures 1x1 while the card is up. Capture `06a-…png` viewed: notice above THE JOB, nothing covered.
  - IF-001 sweep re-run (`bug-0003-fix-2026-10-19/sweep/`): ALL SURFACES CLEAN, 44 ok / 0 not ok.
  - `npx vitest run`: 1,540/1,540. `npm run lint` no errors. `npm run build` completes.
- **Not checked**: text scales other than 100% in the failure-plus-orientation state (the card's rows scroll; not measured).
