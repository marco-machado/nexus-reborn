## Fix (2026-10-19)
- Design call (Marco Machado, 2026-10-19): the Feed **redacts** the codename of a contract that intel hides; the line stays (keeps UNREAD honest). The codename shows once intel reaches the gate or Expedite waives it.
- `src/state/worldStore.ts`: every contract Feed line (POSTED, EXPIRED, RAID WITHDRAWS, RE-CLIENTED) carries `contract: { id, codename, intelReq }`. New `feedText(event, contracts, intelLevel)` swaps the codename for `[REQUIRES INTEL LVL n]`; an open record uses its live gate (`contractIntelReq`, Expedite-aware), a closed record the gate stored at post. Event text and RNG unchanged.
- `src/state/save.ts`: `validEvent` accepts and checks the optional ref; v10 saves without it stay valid.
- `src/ui/WorldMap.tsx`: `FeedRow` renders `feedText` in the text and the aria-label.
- Verified: `npm test` 1545/1545, `npm run lint` clean, `npm run build` OK. In-app browser on `npm run dev` (continued campaign, intel 1): forced a SEVERE contract COLD ANTHEM (gate 3) in North America (Pacifica).
  - Feed: `OPEN CONTRACT [REQUIRES INTEL LVL 3] POSTED IN PACIFICA` (aria-label the same). Clicking it focused North America; OPEN CONTRACTS listed only the authored RUST HAVEN, not the generated offer.
  - Intel set to 3: Feed showed `OPEN CONTRACT COLD ANTHEM POSTED IN PACIFICA`; back to 1: redacted again.
  - Reload + CONTINUE: the save kept the ref, the line stayed redacted, no console errors.
  - Not reproduced: the tester's exact FERAL LEDGER / São Paulo case (seeded state differs); Expedite reveal covered by the unit test only.
