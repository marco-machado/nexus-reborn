2. **Settle check**: `document.getAnimations()` never reaches 0 on World Network. The one running animation is `blink` on `section.panel.corners.wm-time > … > i.wm-live-dot` (the LIVE dot, infinite iterations). 3. **Influence note below the fold**: in the probe's `influence-note` fixture (`influence: 8`, `selected: 'na'`) at 1280×720, the note sits in `.wm-sector-scroll` (clientHeight 285, scrollHeight 409, scrollTop 0) below the visible area. Its `UNDERSTOOD` box is 96.2×24, but at scroll 0 nothing of it is drawn and pointer hits at its box land on the panel behind. So R1's `if-035-influence-note.png` does not show the note. Once scrolled into view it is visible, ≥24×24, and clear of neighbours. IF-035's AC is about target size and overlap, not placement, so this is not an IF-035 fail. Whether the first-time note should appear in view without scrolling is a question for the UX spec (`design/ux/world-network.md`) and qa-lead to decide. Also in the scrolled capture, the panel's scroll-down chevron draws over the note's second line (`STABILIZE`).
4. **Raw-box overlap is a false positive in scroll lists**: overlap tests on `getBoundingClientRect()` report contract rows the list has scrolled out of view. Pass 2 uses each box clipped by its overflow ancestors. IF035-14/-15/-16 hold no scrolled content, so their raw-box results stand.
