## Notes

1. **Harness defect, not an app defect.** In run 1, the orientation card stayed up in every state, even after the probe's `dismissCard()`. DIAG in run 2's `run.log`:
   `{"card":true,"seenViaImport":true,"tutorialUrls":[".../src/game/tutorial.ts?t=1792893423482",".../src/state/tutorialStore.ts?t=1792893423482",".../src/state/tutorialStore.ts"]}`
   The app runs the HMR-stamped `tutorialStore.ts?t=…`. The probe's bare-path import gets a second store copy. `markSeen` lands on that copy (`seenViaImport: true`), so the card the app renders never closes.
   - **Effect on run 1:** at 125% the card covers the banner line in `run-1/if-016-failed-scale-125-1280x720.png`. `clipped()` excludes `.hud-menu-wrap` overlays, so it reported `[]` anyway. The R1 captures `r1-probe/if-016-017-failed.png` and `if-016-complete.png` show the card up too, but at 100% it does not cover the banner.
   - **Fix (script only):** run 2 dismisses the card by clicking UNDERSTOOD (`ensureCardGone`, which throws if the card stays up) and then pauses. The card was gone in every run-2 state.
   - **For qa-lead:** the same separate-copy problem may affect other R1 checks that rely on `dismissCard()` or the "card dismissed" precondition.
2. **Count observation for qa-lead (not an IF-016 failure, per IF-016-04 pass criteria).** The failed banner hardcodes `0 / {MISSIONS.length}`. Variant B (one contract won) reads `0 / 3`, while the UX spec asks for `n / 3` (`design/ux/world-network.md` line 157).
3. **IF-016-02 precondition.** `git status --porcelain src` printed ` M src/game/tutorial.test.ts`, ` M src/state/tutorialStore.test.ts` and `?? src/game/world.noRoute.test.ts`. These are uncommitted test files that were already in the working tree, not files from this session. Both `rg` runs searched that tree and found no match.
4. **Banner line at 90% text scale renders at 9 px** (`fontPx: 9`; 10 at 100%, 11 at 110%, 12.5 at 125%). The R1 IF-026 10 px floor check runs at 100% only. Whether the floor applies below 100% is a question for qa-lead / IF-026, not an IF-016 criterion.
5. Variant A and B and the IF-016-06 walk used the cases' Common-setup `out(...)` helper and `reportMission`, the Debrief path. No campaign flag was set by hand in those cases.
