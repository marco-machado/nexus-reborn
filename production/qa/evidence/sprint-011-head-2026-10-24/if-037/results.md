## Story verdict: **FAIL**

The CSS cap works: computed size is 11.66 px at both 110 and 125. But the tree SVG is fitted with `meet` into a column that gets shorter as the text grows. The header wraps to three lines at 125 (`tc03-research-125.png`), so the drawn label is 11.29 px at 110 and 10.03 px at 125, against 11.68 px expected. The case defines "follows the text scale" by rendered size. If qa-lead rules that computed size is the measure, TC-03 would pass and the story verdict would become PASS WITH NOTES.

## Notes

1. **R3 script defect, not an app defect.** In `focus.mjs` step 4, the script removes `hint-debrief-research` from seen and then calls `SURFACES.debrief()`. That calls `team()`, which calls `fresh()`, and `fresh()` marks the hint seen again. So `after UNDERSTOOD focus is on RETURN TO WORLD NETWORK` never runs, and `FAIL Debrief research note shows on the first Debrief // no note` is printed instead. With the removal moved after `team()`, the note shows and the check passes (TC-037-12). R3 exits 1 at HEAD for this reason alone.
2. **Rendered label size at 125 is 10.03 px**, 0.03 px above the 10 px floor in art bible §7.5. Any further shrink of the tree column at 125 would break the floor.
3. Under reduced motion, the Recruitment Market portraits keep a `blink` opacity animation on `.pp-live` (the portrait's live indicator). It is not on the overlay root or panel, so it does not affect TC-037-15. Whether a blinking live dot should stop under reduced motion is a design question for the reduced-motion spec, not an IF-037 AC.
4. TC-037-20 reading: under reduced motion the rows print with no animation at all, which the CSS comment states on purpose ("with reduced motion they appear at once"). The case's "every animation is `row-in` ≤ 120 ms, opacity-only" holds because there are none. With reduced motion **off**, every row runs `row-in`, 120 ms, keyframes `opacity` only, with identical rects, so the ≤120 ms no-travel fade exists in the default mode. qa-lead may want to confirm that the AC's "GIVEN reduced motion … print by a ≤120 ms fade" accepts an instant print.
5. In `tc05-market-125.png`, the Assembly detail panel behind the market (dimmed) shows the stat label "MOBILITY" broken mid-word as "MOBILIT / Y" at 125. It is outside the market overlay, and R2's `team` @125 capture does not show that section, so no IF-037 case measures it. Worth a look on the Assembly surface at 125.
6. Settings from Pause: the first read in TC-037-15 came 62 ms after the click. It is the first mount of the dialog (observer callback), so no earlier frame exists. Opacity was already 1.
7. Housekeeping: my script closed its browser (`browser.close()`, exit 0 both runs). The dev server was left running as instructed. While this run was being checked, a separate headless Chrome for Testing was running under `node production/qa/evidence/sprint-011-head-2026-10-24/tm-020/probe.mjs` (another task's probe). It is not from this run and was not touched.
