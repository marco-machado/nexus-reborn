## Notes (observations, not AC failures)

1. **`TYPE // CITY` is not shown on locked rows.** As built (`src/ui/WorldMap.tsx:1050-1056`), a locked row puts the reason `<i className="red">` where an open row has `<i className="dim">TYPE // CITY</i>`. AC-1 names "codename, `TYPE // CITY` and chips in Ink or brighter". Every run that is present meets that. The spec (`design/ux/world-network.md:170`) says only "Locked authored rows show the intel gate in text". Whether a locked row should also print `TYPE // CITY` is a design question for qa-lead or the owner, not a defect against this story.
2. **At 1280x720, the OPEN CONTRACTS list shows about one row.** In `eu`, the open NEON GARDEN row sits below the fold. As a result, neither the R1 grayscale capture nor `tc10-gray-eu.png` shows a locked row next to an open row in one frame. TC-10 was compared across captures, plus a scrolled capture (`tc10-gray-eu-scrolled.png`). R1's "frame differs" check reads that off-screen row from the DOM. The values are valid, but no single image shows them side by side.
3. **The R1 IF-029 frame comparison ignores `border-style`** (concern 4 in the cases file). The hand-walk recorded it: locked rows are `dashed`, open rows `solid`, in both modes. Background also differs (`rgba(0, 0, 0, 0)` vs `rgba(4, 10, 9, 0.9)`). Border colour is the same.
4. **The lock glyph uses Ink, not the Ink Dim that the story's Implementation Notes name** (`src/ui/ui.css:1517`, concern 3 in the cases file). Measured: 12.68:1 default, 17.18:1 HC. The AC sets only a >= 3:1 floor.
5. **The HC Ink Dim / Ink Faint remaps** are `rgb(157, 195, 184)` and `rgb(109, 147, 138)`, read from `--ink-dim` / `--ink-faint`. No locked-row run uses either value.
6. **Harness**: the cases file's setup step 4 asks for helpers "copied verbatim". The copy also brought in `setScale`, which sits between `dismissCard` and `setHC` in `probe.mjs` and is never called. Pixel sampling decodes page screenshots in a separate `about:blank` page and never touches the app page. On the first run the script failed with `ReferenceError: install is not defined`, a copy-range error in the script, which was fixed. TC-10's scrolled capture was added and the whole script re-run. The results above come from that final run.
7. **Evidence location**: per the strategy and the orchestrator, evidence is in `sprint-011-head-2026-10-24/if-029/`, not the story's `production/qa/evidence/if-029/` (concern 2 in the cases file, open for qa-lead).
