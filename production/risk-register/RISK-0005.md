# Risk: Only Chromium has been measured

## Identification

- **ID**: RISK-0005
- **Identified By**: Claude, delegated by the owner's /goal 2026-10-23
- **Date Identified**: 2026-10-23
- **Category**: Quality

## Assessment

- **Probability**: Medium
- **Impact**: Moderate
- **Risk Score**: Medium

## Description

Every probe, sweep, perf run and playtest uses Chrome for Testing (playwright-core). The target is 'Desktop browser'. Firefox and Safari WebGPU and fallback paths are unmeasured.

## Trigger Conditions

- A render or audio difference reported from another browser

## Impact Analysis

### If This Risk Materializes

A player on another browser could hit a broken render path or layout.

### Affected Systems/Features

- Rendering
- Interface
- Audio

## Mitigation Strategy

### Prevention (reduce probability)

- Firefox and Safari smoke check in Sprint 13
- Owner: qa-lead

### Contingency (reduce impact if it occurs)

- If a browser fails, either fix or state the supported browsers on the menu and store page
